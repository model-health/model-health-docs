## What you'll need

- **A laptop or tablet** — for running the web app at [app.modelhealth.io](https://app.modelhealth.io). Any modern device and browser works.
- **At least 2 iOS devices** — for recording. Any model released in 2018 or later. See the [list of supported devices](#supported-ios-devices-for-recording) below.
- **Tripods and phone holders** — for stabilizing each recording device. One per iOS device.
- **Checkerboard** — for camera calibration. Print [this checkerboard](/img/docs/getting-started/checkerboard-4x5-35mm.pdf) on A4 paper and mount it to a flat surface.

:::warning Measure your checkerboard squares
Print at **actual size (100% scale)** with no scaling and no "Fit to Page". The expected square size is exactly **35mm**.

In case your printed checkerboard does not have exactly 35mm squares, **update your checkerboard dimensions in the app Settings** — this is critical for accurate measurements.
<ZoomableImage src="/img/docs/getting-started/update-checkerboard-default.png" alt="Checkerboard setup" style={{width: '280px', marginLeft: '2rem', marginBottom: '0.5rem'}} />

:::

- **A stable internet connection** — required for both the iOS app and web platform. Recording devices don't need to share the same network, but each needs connectivity to sync with the web app.

## Web App

The web app is where you guide the recording flow, review results, and export reports. Visit [app.modelhealth.io](https://app.modelhealth.io) to create an account.

<details>
